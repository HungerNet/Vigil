# Vigil brand

<img src="../assets/brand/vigil-app-icon.png" width="128" alt="Vigil app icon">

## Idea

A *vigil* is a period of staying awake to keep watch. Vigil keeps watch so the player does not
have to, and it reports only what it can explain.

**Keywords:** vigilance, observation, awareness, investigation, intelligence, precision,
confidence, trust.

**Positioning:** a premium software platform for detection and analysis, not a gaming client.

## Logo

A geometric **V**. The outer silhouette is strictly straight (precision); the inner notch is a
gentle bowl, the lower lid of an attentive eye, in which a single point of focus rests. The first
read is the V. The observation idea comes second and stays quiet: no literal eye, no shield,
sword or mascot. The point can be read as an iris, a pearl in its setting, or the candle of a
vigil.

| File | Use |
|---|---|
| `assets/brand/vigil-mark.svg` | Mark in ink with the iris focus point |
| `assets/brand/vigil-mark-mono.svg` | Single color (`currentColor`), for embossing, favicons, monochrome contexts |
| `assets/brand/vigil-lockup.svg` | Mark + VIGIL wordmark |
| `assets/brand/vigil-app-icon.svg` / `.png` | Application, splash and social profile icon |
| `assets/brand/vigil.ico` | Launcher icon (16–256 px) |

All of these are generated by `tools/make_brand_assets.py` from the same geometry the UI uses
(`src/ui/icons.cpp`). At 32 px and below the mark is scaled up within the tile for legibility.

**Construction** (unit square): top edge at y 0.105; arms 0.035–0.315 and 0.685–0.965; vertex
(0.5, 0.935); notch = quadratic curve through control (0.5, 0.70); focus point (0.5, 0.30),
r 0.085.

**Clear space:** half the mark's height on every side. **Minimum size:** 16 px (the focus point
may merge with the bowl at that size; the V must remain).

## Wordmark

VIGIL in Inter SemiBold, uppercase, tracked +0.2 em. Always paired with the mark at a height of
about 45% of the mark.

## Color

| Token | Hex | Use |
|---|---|---|
| Midnight ink | `#0E1117` → `#131722` | Primary surfaces |
| Ink text | `#E8ECF3` | Mark body, primary text on dark |
| Iris | `#8FA8FF` | Brand accent, focus point, selection |
| Vigil gold | `#E2B866` | Secondary warmth (Vesper theme, special moments) |
| Clear | `#5CC8B2` | Severity: nothing notable |
| Notice | `#E8B35A` | Severity: rising |
| Alert | `#F0766A` | Severity: high |
| Critical | `#E5484D` | Severity: detection |

Color carries meaning: surfaces stay quiet, and the severity scale is reserved for confidence.

## Typography

Inter (SIL OFL 1.1) for everything; Inter Display for headings and metrics; a system monospace
for raw values. Scale: 10.5 overline (tracked caps) · 11 · 12 · 13 · 14 · 16 · 24 · 28 · 32.

## Voice

Precise, calm, evidential. Vigil reports observations and never accuses.

- ✓ "Hit Fennick from 3.91 blocks."
- ✓ "Jump landed after 8 ticks on flat ground."
- ✗ "HACKER DETECTED!!"

Chat signature: `§8[§9Vigil§8]`.
